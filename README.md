# Task 1 – LoRA fine-tuning (Qwen2.5-0.5B-Instruct)

Task: convert plain-English expense text into a fixed JSON format
(`amount`, `category`, `merchant`, `payment`).

## How to reproduce (Colab T4 GPU)

1. `pip install -q -U peft accelerate`
2. `python gen_data.py` – generates `train.jsonl` (800) and `test.jsonl` (100)
3. `python train_eval.py` – evaluates the base model, trains LoRA, evaluates the fine-tuned model; writes `results.json`, `failures.json` and `lora_adapter/`
4. `python eval_hard.py` – runs 25 hand-written stress cases; writes `hard_results.json`

## Files

- `gen_data.py`, `train_eval.py`, `eval_hard.py` – code
- `train.jsonl`, `test.jsonl` – data
- `results.json`, `failures.json`, `hard_results.json` – outputs from my own runs
- `lora_adapter/` – adapter config. The weights file (`adapter_model.safetensors`, about 35 MB) is not included because of GitHub's web-upload size limit; it is regenerated by running `train_eval.py` (about 1.5 minutes on a T4).

## Key results (from my runs)

| Test set | Base | Fine-tuned |
|---|---|---|
| Held-out test (100 examples), exact match | 0.13 | 0.99 |
| Hard stress set (25 examples), exact match | 0.16 | 0.68 |

Training time: 1.4 min. Peak GPU memory: 6.49 GB. Trainable parameters: 8,798,208 (1.75%).
